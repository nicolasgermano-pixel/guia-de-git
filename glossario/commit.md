

# commit

Um commit no Git é um registo definitivo das alterações efetuadas nos ficheiros do seu repositório local. Funciona como um ponto de restauro (snapshot) do projeto num momento específico, permitindo acompanhar a evolução do trabalho e voltar atrás se for necessário. 
Exemplo prático de uso: após preparar as alterações, utilizamos o comando `git commit -m "Acrescenta a entrada commit"` para gravar essa versão no histórico.
